# 📊 Завдання: Стовпчасті та кругові діаграми (6 клас)

---

## 1️⃣ Улюблені фрукти (Стовпчаста діаграма)

| Фрукт     | Кількість учнів |
|-----------|----------------|
| Яблуко    | 8              |
| Банан     | 5              |
| Апельсин | 4              |
| Груша     | 3              |

**Завдання:**
1. Побудуй стовпчасту діаграму за цими даними.  
2. Визнач, який фрукт найпопулярніший.  
3. На скільки більше учнів обрали яблуко, ніж грушу?  
4. Скільки всього учнів брали участь в опитуванні?  

> **Підказка для Excel:**  
> - Виділи таблицю → Вставка → Стовпчаста → Вибери стиль діаграми.  
> - Додай назву діаграми: *“Улюблені фрукти учнів”*.

---

## 2️⃣ Жанри книг у бібліотеці (Кругова діаграма)

| Жанр          | Кількість книг |
|---------------|----------------|
| Казки         | 10             |
| Пригоди       | 6              |
| Енциклопедії  | 4              |

**Завдання:**
1. Обчисли загальну кількість виданих книг.  
2. Визнач, яку частину становлять казки (дріб або %).  
3. Побудуй кругову діаграму.  
4. Який жанр найменш популярний?  

> **Підказка для Excel:**  
> - Виділи таблицю → Вставка → Кругова → Вибери стиль.  
> - Додай підписи секторів: *“Жанр – %”*.

---

## 3️⃣ Продаж зошитів за тиждень (Стовпчаста діаграма)

| День       | Продано зошитів |
|------------|-----------------|
| Понеділок  | 12              |
| Вівторок   | 9               |
| Середа     | 15              |
| Четвер     | 6               |
| П’ятниця   | 18              |

**Завдання:**
1. Побудуй стовпчасту діаграму.  
2. У який день продано найбільше зошитів?  
3. На скільки більше продано у п’ятницю, ніж у четвер?  
4. Чи можна ці дані зобразити круговою діаграмою? Поясни.  

> **Підказка для Excel:**  
> - Виділи таблицю → Вставка → Стовпчаста → Додай назву: *“Продаж зошитів за тиждень”*.
