
# 12 міні-ігор для Python у Thonny
 
> Відкрийте Python у Thonny → попросіть ChatGPT створити гру → вставте код → запустіть → пограйте → змініть щось самі.

---

## 1. 🐍 Міні Snake

**Що вивчать:** рух, клавіші, цикл гри.

### Що попросити ChatGPT

```text
Створи просту гру Snake на Python для Thonny використовуючи pygame.
```

### Ідеї для покращення

- додати рівні;
- змінити швидкість;
- зробити різні кольори змійки.
