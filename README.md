# Практична робота: GIF «Стрибуча кулька»

**Мета:** навчитися створювати послідовність кадрів у Photoshop та збирати їх у анімаційний GIF через онлайн-сервіс [ezgif.com](https://ezgif.com/maker).

**Час:** 45 хвилин суцільної практичної роботи

---

## Завдання

1. **Створення нового документа в Photoshop**  
   - File → New  
   - Розмір: **400×400 px**  
   - Фон: білий або світло-сірий

2. **Створення кадрів анімації**  
   - Кожен кадр = **окремий файл (PNG або JPG)**  
   - Кількість кадрів: 10–12 (чем більше кадрів, тим плавніше анімація)  

### Приклад кадрів для «стрибучої кульки»

| Кадр | Позиція кульки | Колір кульки | Примітка |
|------|----------------|--------------|----------|
| 1    | на землі       | червона      | Початок стрибка |
| 2    | трохи вище     | помаранчева  | Стрибок вгору |
| 3    | ще вище        | жовта        | Середина стрибка |
| 4    | на піку        | зелена       | Максимальна висота |
| 5    | трохи нижче    | синя         | Початок падіння |
| 6    | ще нижче       | фіолетова    | Приземлення |
| 7    | на землі       | червона      | Кулька відскакує |
| 8–10 | повторення руху| червона-жовта| Можна додати відблиски або тінь |

> Кожен кадр зберігати як окремий файл: `frame1.png`, `frame2.png`, …  

---

3. **Збірка GIF онлайн**  

1. Відкрити [https://ezgif.com/maker](https://ezgif.com/maker)  
2. Натиснути **Choose Files** → вибрати всі кадри (`frame1.png` … `frame10.png`)  
3. Натиснути **Upload and make a GIF**  
4. Встановити:
   - **Frame delay:** 50–100 (мс) → 0.05–0.1 сек на кадр  
   - **Loop forever**  
5. Натиснути **Make a GIF**  
6. Завантажити готовий GIF  

---

## Розподіл часу на 45 хвилин

- 0–5 хв: створення документа та вибір кольорів  
- 5–30 хв: малювання всіх кадрів кульки на шарах і збереження файлів  
- 30–40 хв: перевірка кадрів, додавання тіні/ефектів (опційно)  
- 40–45 хв: завантаження кадрів на ezgif.com і збереження GIF  

---

## Поради

- Використовуй простий рух кульки по вертикалі для ефектної анімації  
- Можна додати тінь або невеликі відблиски, щоб анімація виглядала цікавіше  
- Зберігати файли кадрів окремо (`frame1.png`, `frame2.png`, …) для зручного завантаження на ezgif
