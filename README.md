Основи HTML – Практичне завдання
Приклад простої HTML-сторінки
<!DOCTYPE html>
<html>
<head>
    <title>Моя сторінка</title>
</head>
<body>
    <h1>Привіт!</h1>
    <p>Це моя перша сторінка.</p>
</body>
</html>
🔹 Основні теги HTML
1. Заголовки

HTML-теги для заголовків:

<h1>Заголовок 1</h1>
<h2>Заголовок 2</h2>
<h3>Заголовок 3</h3>

Завдання:
Створити сторінку «Моє хобі» з різними рівнями заголовків.

2. Абзаци

HTML-тег для абзацу:

<p>Це абзац тексту.</p>

Завдання:
Написати 3 абзаци про себе:

Хто я

Що люблю робити

Мої плани або мрії

3. Списки

Нумерований список:

<ol>
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ol>

Маркований список:

<ul>
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ul>

Завдання:
Створити список улюблених предметів у школі (5 предметів).

4. Посилання
<a href="https://google.com">Перейти в Google</a>

Завдання:
Додати посилання на свій улюблений сайт.

5. Зображення
<img src="cat.jpg" alt="Кіт">

Завдання:
Додати картинку на сторінку (можна фото з комп’ютера або з інтернету).

6. Таблиці
<table border="1">
  <tr>
    <th>Ім'я</th>
    <th>Вік</th>
  </tr>
  <tr>
    <td>Андрій</td>
    <td>14</td>
  </tr>
</table>

Завдання:
Створити таблицю «Мій клас» з колонками: Ім’я, Вік, Улюблений предмет.
