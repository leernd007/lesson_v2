## Canva — створення рекламної продукції

Оберіть **ОДНЕ** із запропонованих завдань та створіть дизайн у Canva.

---

# Варіант 1 — Музичний фестиваль

Створіть:
- афішу
- квиток
- флаєр

Для вигаданого музичного фестивалю.

### Обов’язково вказати:
- назву фестивалю
- дату та час
- місце проведення
- короткий опис
- організатора
- контактну інформацію

### Стиль:
Яскравий, сучасний, молодіжний.

---

# Варіант 2 — Кіберспортивний турнір

Створіть:
- афішу
- квиток
- флаєр

### Обов’язково вказати:

- місце проведення

Технологічний, неоновий, сучасний.

---

# Вимоги до роботи

- Усі матеріали повинні бути виконані в одному стилі
- Використовуйте:
  - текст
  - іконки
  - зображення
  - кольорові елементи
- Дизайн має бути:
  - читабельним
  - охайним
  - креативним
