🔹 Основні теги, які варто вивчити
📌 1. Заголовки

<h1>Заголовок 1</h1>
<h2>Заголовок 2</h2>

Завдання:

Створити сторінку "Моє хобі" з різними рівнями заголовків.

📌 2. Абзаци

<p>Це абзац тексту.</p>

Завдання:

Написати 3 абзаци про себе.

📌 3. Списки
Нумерований список:

<ol>
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ol>

Маркований список:

<ul>
  <li>Пункт 1</li>
  <li>Пункт 2</li>
</ul>

Завдання:

Зробити список улюблених предметів.

📌 4. Посилання

<a href="https://google.com">Перейти в Google</a>

Завдання:

Додати посилання на улюблений сайт.

📌 5. Зображення

<img src="cat.jpg" alt="Кіт">

Завдання:

Додати картинку на сторінку.
