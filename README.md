# Основи HTML – Практичне завдання

## Приклад простої HTML-сторінки

```html
<!DOCTYPE html>
<html>
<head>
    <title>Моя сторінка</title>
</head>
<body>
    <h1>Привіт!</h1>
    <p>Це моя перша сторінка.</p>
</body>
</html>
```

# 🔹 Основні теги HTML

## 1. Заголовки

HTML-теги для заголовків:

```html
<h1>Заголовок 1</h1>
<h2>Заголовок 2</h2>
<h3>Заголовок 3</h3>
```

## Завдання:
**Створити сторінку «Моє хобі» з різними рівнями заголовків (h1, h2, h3).**

## 2. Абзаци

Тег для абзацу:

```
<p>Це абзац тексту.</p>
```
## Завдання:
**Написати 3 абзаци про себе:**

- Хто я
- Що люблю робити
- Мої плани або мрії
